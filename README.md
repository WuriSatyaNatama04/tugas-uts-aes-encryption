## Deskripsi Tugas
Program ini dibuat untuk mengimplementasikan enkripsi dan dekripsi file menggunakan algoritma **AES** dengan library `pycryptodome`.

## Fitur Program
- Enkripsi file (menggunakan password)
- Dekripsi file
- Menggunakan **AES-256** dengan mode **CBC**
- Derivasi key menggunakan SHA-256

## Cara Menjalankan Program

```bash
# Install library terlebih dahulu
pip install pycryptodome

# Jalankan program
python aes.enkripsi.py
